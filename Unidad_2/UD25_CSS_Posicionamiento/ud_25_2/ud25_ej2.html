Redes

Una red informática es un conjunto de equipos conectados entre sí para compartir información y recursos. Pueden ser tan pequeñas como la red de casa, con un router y un par de dispositivos, o tan grandes como Internet, que une millones de redes de todo el mundo. Para que todos los equipos se entiendan, se usan protocolos comunes como TCP/IP.

Cada equipo de la red tiene una dirección IP que lo identifica, igual que una dirección postal. Los routers se encargan de decidir por dónde viaja cada paquete de datos hasta llegar a su destino, mientras que los switches conectan los equipos dentro de una misma red local. Entender cómo se reparten las direcciones y cómo se dividen las redes en subredes es una de las bases del administrador de sistemas.

Además del cableado y los dispositivos, una red necesita servicios para funcionar bien: DHCP para repartir direcciones automáticamente, DNS para traducir nombres como google.com a direcciones IP, y herramientas de monitorización para detectar fallos antes de que los usuarios se den cuenta.

Sistemas

El sistema operativo es el programa que hace de puente entre el hardware y las aplicaciones. Se encarga de gestionar la memoria, el procesador, los discos y los periféricos, para que el resto de programas no tengan que preocuparse de esos detalles. Los más conocidos son Windows, Linux y macOS.

En el mundo de los servidores, Linux es el gran protagonista por su estabilidad, su seguridad y porque es software libre. Distribuciones como Ubuntu Server, Debian o Rocky Linux se usan para montar servidores web, de correo o de bases de datos. Windows Server, por su parte, domina en las empresas que trabajan con Active Directory para gestionar usuarios y equipos.

Administrar sistemas implica instalar y actualizar el software, crear y gestionar usuarios y permisos, programar copias de seguridad y vigilar el rendimiento. Cada vez es más habitual automatizar estas tareas con scripts y herramientas de configuración, para no tener que repetir a mano el mismo trabajo en decenas de máquinas.

Web

Una página web se construye con tres tecnologías que trabajan juntas. HTML define la estructura y el contenido: títulos, párrafos, imágenes y enlaces. CSS se encarga de la presentación: colores, tipografías, tamaños y la colocación de cada elemento. JavaScript añade el comportamiento, como menús desplegables o formularios que se comprueban solos.

Separar el contenido de la presentación es una de las ideas más importantes del desarrollo web. Gracias a las hojas de estilo externas, una misma página puede verse bien en un ordenador, en una tableta o en un móvil, y cambiar el diseño de toda una web puede ser tan sencillo como editar un único archivo CSS.

Para que una web llegue a los usuarios hace falta un servidor web, como Apache o Nginx, que entrega los archivos cuando alguien los pide desde el navegador. Además, hoy en día es imprescindible servir las páginas por HTTPS, que cifra la comunicación entre el navegador y el servidor.

Seguridad

La ciberseguridad se ocupa de proteger los sistemas, las redes y los datos frente a ataques, accesos no autorizados y pérdidas de información. Se suele resumir en tres objetivos: confidencialidad, que solo acceda quien debe; integridad, que los datos no se modifiquen sin permiso; y disponibilidad, que los servicios funcionen cuando se necesitan.

Las amenazas más habituales son el phishing, que engaña a los usuarios para robar sus contraseñas, el ransomware, que cifra los archivos y pide un rescate, y la explotación de vulnerabilidades en programas sin actualizar. Por eso son tan importantes las actualizaciones, las contraseñas robustas, la autenticación en dos pasos y las copias de seguridad.

En las empresas, un SOC o centro de operaciones de seguridad vigila de forma continua lo que ocurre en la red. Con herramientas como un SIEM se recogen y analizan los registros de los equipos para detectar comportamientos sospechosos y responder a los incidentes lo antes posible.
