Mis proyectos

Laboratorio de red doméstica

Monté una pequeña red virtual con VirtualBox formada por un router pfSense, un servidor Linux y dos equipos cliente. El objetivo era practicar la segmentación en VLAN y la configuración de reglas de cortafuegos para separar los equipos de invitados del resto de la red.

Análisis de correos de phishing

Recopilé una colección de correos fraudulentos recibidos durante varios meses y analicé sus cabeceras, remitentes y enlaces. Con los resultados elaboré una pequeña guía para ayudar a familiares y compañeros a reconocer las señales más habituales de este tipo de engaño.

Página web personal

Este mismo sitio web, creado desde cero con HTML en Visual Studio Code y publicado en GitHub. Me ha servido para aprender la estructura básica de un documento HTML, el uso de enlaces entre páginas y la validación con el validador del W3C.
